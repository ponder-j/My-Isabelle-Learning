## # 与 @
### 1. # (Cons)：连接“元素”和“列表”

- **含义**：构造列表（Construct），把一个元素加到列表的**最前面**。
- **类型**：`'a ⇒ 'a list ⇒ 'a list` （左边是元素，右边是列表）
- **你的代码例子**：`x # xs`
    - `x` 是一个**元素** (类型 `'a`)
    - `xs` 是一个**列表** (类型 `'a list`)
    - **结果**：一个新的列表。

### 2. `@` (Append)：连接“列表”和“列表”

- **含义**：拼接（Append），把两个列表首尾相接。
- **类型**：`'a list ⇒ 'a list ⇒ 'a list` （左右两边都必须是列表）
- **你的代码例子**：`reverse xs @ [x]`
    - `reverse xs` 的结果是一个**列表**。
    - `x` 是元素，**不能直接用 `@`**。
    - 所以必须写成 `[x]`（即 `x # []`），把它变成一个**单元素列表**。
    - 然后用 `@` 把这两个列表拼起来。
