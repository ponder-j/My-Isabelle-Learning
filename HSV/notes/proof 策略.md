# Isabelle/HOL 常用证明规则汇总

在 Isar 结构化证明中，`proof (rule ...)` 是拆解目标的核心手段。以下是按逻辑类型分类的高频规则速查表。

后缀 **I** 代表 **Introduction (引入规则)**，用于将目标分解或转化为更易证明的形式。

## 1. 逻辑连接词规则 (拆解目标结构)

当你看到目标包含以下符号时，使用对应的规则：

|   |   |   |   |
|---|---|---|---|
|**规则名称**|**适用目标 (Goal)**|**效果 (Effect)**|**对应 Isar 结构**|
|**`impI`**|`A ⟶ B` (蕴含)|将 `A` 移入假设，目标变为 `B`|`assume A show B`|
|**`conjI`**|`A ∧ B` (合取/且)|**分裂**成两个子目标：分别证明 `A` 和 `B`|`show A ... show B`|
|**`notI`**|`¬ A` (非)|假设 `A` 成立，目标变为 `False` (即反证法)|`assume A show False`|
|**`disjI1`**|`A ∨ B` (析取/或)|放弃 B，只证明 `A`|`show A`|
|**`disjI2`**|`A ∨ B` (析取/或)|放弃 A，只证明 `B`|`show B`|
|**`iffI`**|`A ⟷ B` (当且仅当)|分裂为两个方向：`A ⟹ B` 和 `B ⟹ A`|证明双向蕴含|

## 2. 量词规则

|   |   |   |   |
|---|---|---|---|
|**规则名称**|**适用目标 (Goal)**|**效果 (Effect)**|**备注**|
|**`allI`**|`∀x. P x` (任意)|引入一个新的固定变量 `x`，证明 `P x`|对应 Isar 的 `fix x`|
|**`exI`**|`∃x. P x` (存在)|告诉 Isabelle 存在某值。|通常需配合 `rule_tac x="值" in exI` 手动指定值，或留给自动化工具猜测。|

## 3. 集合论规则 (非常常用)

|   |   |   |
|---|---|---|
|**规则名称**|**适用目标 (Goal)**|**效果 (Effect)**|
|**`subsetI`**|`A ⊆ B` (子集)|引入任意元素 `x`，假设 `x ∈ A`，证明 `x ∈ B`|
|**`equalityI`**|`A = B` (集合相等)|分裂为两个子目标：证明 `A ⊆ B` 和 `B ⊆ A`|

## 4. 实战小技巧：`standard` 规则

很多时候，你其实**不需要**显式写出这些规则的名字。

- **默认行为**：如果你只写 `proof` (不带任何参数)，Isabelle 会自动识别当前目标的顶层逻辑符号，并应用最“标准”的引入规则（Standard Rule）。
    
    - 如果目标是 `∀x. P x`，写 `proof` 等价于 `proof (rule allI)`。
        
    - 如果目标是 `A ⟶ B`，写 `proof` 等价于 `proof (rule impI)`。
        
- **何时必须手动写？**
    
    - 当你不想用默认规则时。
        
    - 当默认规则有歧义时（例如面对 `A ∨ B`，Isabelle 不知道你想证哪一边，必须写 `proof (rule disjI1)`）。
